### Matriz de Transformación: Problemas, Necesidades y Requisitos Funcionales

| # | Problema Identificado | Necesidad de Software | Requisito Funcional (RF) |
| :---: | :--- | :--- | :--- |
| **1** | Pérdida de tiempo y aglomeraciones en recepción por agendamiento telefónico o manual de citas. | Plataforma web integral de agendamiento y gestión de turnos que automatice la reserva, reasignación, disponibilidad horaria y visualización de costos tanto para clientes como para recepción. | **RF-01:** El sistema debe permitir al Dueño de la Mascota agendar, reprogramar y cancelar citas seleccionando servicio, veterinario y horario en tiempo real.<br><br>**RF-02:** El sistema debe permitir a la Recepcionista registrar citas presenciales o telefónicas de emergencia en la agenda del día.<br><br>**RF-03:** El sistema debe permitir al Administrador configurar horarios de atención, jornadas laborales y tiempos por consulta para cada veterinario.<br><br>**RF-04:** El sistema debe liberar automáticamente los cupos cancelados y habilitar una lista de espera para notificar a otros clientes.<br><br>**RF-05:** El sistema debe calcular y mostrar el costo estimado del servicio seleccionado antes de confirmar la reserva. |
| **2** | Traspapelo, inconsistencia o pérdida de historias clínicas en papel de los pacientes. | Sistema de expediente médico digital centralizado que garantice el registro de consultas, fórmulas médicas, archivos adjuntos, historial inmutable y acceso a resúmenes para los tutores. | **RF-06:** El sistema debe permitir al Veterinario registrar la consulta médica (motivo, constantes vitales, diagnóstico y observaciones).<br><br>**RF-07:** El sistema debe permitir al Veterinario generar la fórmula médica digital vinculando medicamentos del catálogo con posología y duración.<br><br>**RF-08:** El sistema debe permitir adjuntar y visualizar archivos digitales (PDF, imágenes, exámenes) en la historia clínica del paciente.<br><br>**RF-09:** El sistema debe mostrar un historial médico unificado y cronológico por mascota, restringiendo la edición de registros finalizados.<br><br>**RF-10:** El sistema debe permitir al Dueño de la Mascota consultar y descargar en PDF los resúmenes de sus atenciones médicas. |
| **3** | Olvido de citas e incumplimiento en esquemas de vacunación o desparasitación por parte de los clientes. | Módulo automatizado de notificaciones omnicanal que gestione recordatorios de citas, alertas de vencimiento de vacunas, confirmaciones inmediatas, registro de envíos y preferencias del usuario. | **RF-11:** El sistema debe enviar recordatorios automáticos por correo o SMS al Dueño de la Mascota 24 horas antes de cada cita.<br><br>**RF-12:** El sistema debe generar alertas automáticas al cliente cuando una vacuna o desparasitante esté a 7 días de vencer.<br><br>**RF-13:** El sistema debe registrar un historial de notificaciones enviadas indicando fecha, canal y estado de entrega.<br><br>**RF-14:** El sistema debe enviar un mensaje de confirmación inmediato con el código de reserva tras completar un agendamiento.<br><br>**RF-15:** El sistema debe permitir al Dueño de la Mascota configurar o desactivar los canales preferidos para recibir alertas. |
